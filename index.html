3 Cách để 2 người cùng code trên Antigravity

1 Cách 1: Realtime Live Share (Lập trình trực tiếp thời gian thực)

Thích hợp nhất khi 2 bạn muốn nhìn thấy con trỏ chuột của nhau, cùng chat với AI và cùng sửa file.

  • Người 1 mở Antigravity IDE -> Cài extension Live Share -> Bấm nút Share ở thanh dưới.
  • Copy link gửi cho Người 2.
  • Người 2 mở Antigravity IDE -> Bấm Join và dán link vào. Xong! Cả 2 cùng thao tác và chia sẻ server localhost!
2 Cách 2: GitHub Repository (Chuẩn chuyên nghiệp cho dự án lâu dài)

Thích hợp khi mỗi người làm ở thời gian rảnh riêng, không cần online cùng lúc.

  • Tạo một repository trên GitHub và đẩy toàn bộ thư mục này lên (bao gồm cả file AGENTS.md).
  • Add bạn của anh làm Collaborator trên GitHub.
  • Bạn của anh clone về máy và mở bằng Antigravity. Cả 2 người bảo AI của mình commit theo đúng nhánh: feat/ui và feat/logic.
3 Cách 3: Gửi thẳng File Zip đã nén sẵn (Nhanh nhất trong hôm nay)

Em đã nén sẵn file antigravity-collab-web.zip cho anh.

  • Anh chỉ cần gửi file zip đó qua Zalo / Telegram / Drive cho bạn.
  • Bạn giải nén ra, mở thư mục bằng Antigravity IDE hoặc Antigravity 2.0.
  • Mở file HUONG_DAN_CHO_BAN.md là bạn anh biết chính xác cần làm gì ngay lập tức!
